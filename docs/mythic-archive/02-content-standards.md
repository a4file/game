# Mythic Archive — 콘텐츠 제작 기준서

상위 문서: [00-world-bible.md](./00-world-bible.md), 세력: [01-factions.md](./01-factions.md)

## 데이터 필드 ↔ 로어 훅 (스키마 점검)

백엔드·프론트 공통 시트 구조는 [backend/src/types.ts](../../backend/src/types.ts) 및 에디터 스키마 [frontend/src/editor/sheets/schemas.ts](../../frontend/src/editor/sheets/schemas.ts)를 기준으로 한다. **추가 필드 없이** 아래 필드에 로어를 심는다.

| 시트 | 필드 | 로어 훅 |
|------|------|---------|
| characters | `id`, `name` | 짧은 식별자; 이름은 국가 문법(서약체·기록체)과 어울리게. |
| characters | `description` | **1페이지 요약**: 첫 문장에 세력 태그 `〔…〕` 권장. 갈등축 또는 교리 충돌을 한 번은 명시. |
| characters | `rarity` | “철학적 두께” 메타포와 정렬: 희귀도가 높을수록 `maxPages`·서사 깊이와 일치시킨다. |
| characters | `element` | `fire` \| `water` \| `nature` \| `machine` — **국가와 1:1 매핑 금지**. 전투/상성용 추상; 국가는 태그·서술로만 묶는다. |
| characters | `atk`, `hp` | 수치만으로 성격을 대신하지 말 것. |
| characters | `skillIds` | 스킬 이름·설명과 서사 일관; “서약/기록/파기” 키워드 재사용 가능. |
| characters | `maxPages` | 스토리북 두께 = 존재가 겪어 온 **구속된 사건**의 양. |
| characters | `storyPages[]` | **페이지당 하나의 논점**만. 각 문자열은 짧은 장면·대사·기록 한 줄도 가능. |
| monsters | `name`, `element`, `atk`, `hp`, `skillIds` | 설명 필드는 스키마에 없음 → **이름**에 은유를 심거나, 추후 확장 전까지 `characters`와의 대비로 서사화. |
| maps | `id`, `name` | 스테이지가 다루는 **철학적 사건**을 이름에 녹인다. |
| maps | `recommendedPower` | 난이도; 로어상 “기록의 밀도” 등으로 읽힐 수 있음. |
| maps | `monsterIds` | 해당 구역에서 **어떤 교리가 왜곡**되었는지 몬스터 조합과 맞출 것. |
| skills | `name`, `description` | 명명법·문체는 [03-tone-and-taboos.md](./03-tone-and-taboos.md) 준수. |
| skills | `powerMultiplier`, `cooldown`, `kind` | 서사에서 `kind`를 **교리의 표현**으로 읽힐 수 있게 설명과 맞출 것. |
| weapons / equipments | `name`, `slot`, `rarity`, `atk`, `hp` | 장비는 “기록의 유물”“서약의 잔재” 등으로 명명 가능. |
| items | `name`, `type`, `effect` | 소비·재화·재료가 **어느 국가의 절차**에서 나왔는지 한 힌트. |

**몬스터 서술 공백:** 현재 `Monster`에 `description`이 없다. 몬스터 출현 논리는 맵 이름·몬스터 이름·스킬 설명의 삼각 관계로 보완하거나, 향후 필드 추가 시 이 기준서의 “출현 논리 한 문장”을 그 필드에 옮긴다.

---

## 세력 태그 규칙

- 형식: `〔존재〕` `〔인식〕` `〔도덕〕` `〔논리〕` `〔미〕` `〔질서〕`
- 복합: 최대 두 개, 예: `〔도덕·질서〕`
- 위치: 캐릭터 `description` **첫 문장** 또는 이름 직후 한 줄.

---

## 캐릭터 작성 템플릿

1. **태그 + 한 줄 정체성** (누구이며 무엇을 믿는가)
2. **갈등축** (존재↔인식, 도덕↔질서, 논리↔미 중 최소 하나)
3. **대가** (이 힘을 쓰면 무엇이 깎이는가)
4. **아카이브와의 관계** (기록자인가, 파기자인가, 도피자인가)

`storyPages[]`는 위 네 항목을 **시간 순·강도 순**으로 쪼개 넣는다. 각 페이지는 **한 가지 논점**만 (예: 2페이지에서 “대가”를 처음 인지).

### 캐릭터 검수 체크리스트

- [ ] `description`만 읽어도 **어느 갈등축**에 서 있는지 안다.
- [ ] `〔태그〕`가 있고, [01-factions.md](./01-factions.md)의 **금기**와 충돌하는지 의도적으로 설계되었다.
- [ ] `storyPages` 각 요소가 **서로 다른 논점**을 중복 없이 밀어준다.
- [ ] `element`가 국가 이름을 **대신 설명**하지 않는다.

## 맵(스테이지) 철학적 사건 유형

스테이지 `name` 또는 기획 노트에 아래 중 하나를 태그로 붙인다.

| 유형 코드 | 다루는 일 |
|-----------|-----------|
| `RECORD_TAMPER` | 기록 조작·출처 오염·삭제된 페이지 복원 시도 |
| `OATH_BREAK` | 서약 파기·조건 위반·계약 역류 |
| `VIRTUE_TRIAL` | 도덕적 시험·죄의 무게 실측 |
| `PARADOX_HUNT` | 모순 제거·전제 공격·규칙 충돌 |
| `AFFECT_STORM` | 감정·예술의 과부하·군중 리듬 |
| `STRUCT_LOCK` | 법·계급·허가의 관문·집단 증폭 |

`monsterIds`는 해당 유형을 **증폭시키는 존재**로 구성한다.

## 몬스터 출현 논리

스키마에 전용 필드가 없으므로, 제작 시 **내부 한 줄**을 반드시 적고 이름에 반영한다.

- 형식: **「어떤 교리가 왜곡·폭주·봉인 해제되었는가」**를 한 문장으로.
- 예: “〔인식〕의 금기인 무출처 진실이 군중 확신으로 굳어 파편 생명이 됐다.”

### 몬스터 검수 체크리스트

- [ ] 출현 논리 한 문장이 있다(문서/기획 메모).
- [ ] 연결된 `maps`의 사건 유형과 모순되지 않는다.
- [ ] `skillIds`의 스킬 서술과 **같은 은유 계열**을 쓴다.

---

## 스킬 명명법 · `kind` 연결

### 명명

- **서약체:** `…의 조항`, `전제: …`, `결론: …`, `조건 충족 — …`
- **기록체:** `페이지 …`, `각주 …`, `출처 밝힘`, `침묵 목록`
- **존재·미 계열:** 형상·색·소리·경계 단어 허용; 난해함은 **한 단어 이내**로 제한.

### `kind`와 서사

| kind | 서사적으로 읽히는 것 |
|------|---------------------|
| attack | 교리 **침범**·명제 **부정**·현실 **절단** |
| buff | 서약 **강화**·기록 **증명**·집단 **증폭** |
| debuff | 기록 **훼손**·감정 **오염**·조건 **불이행** |
| support | 출처 **제공**·전제 **보강**·치유는 **서술 복원**으로 표현 권장 |

### 스킬 검수 체크리스트

- [ ] `description`이 숫자(`powerMultiplier`)를 **설명으로 반복**하지 않는다.
- [ ] 이름만 봐도 **어느 세력 어휘**인지 대략 짐작 가능하다.
- [ ] `cooldown`이 길수록 서사상 **대가·재가동 조건**이 있어야 자연스럽다(문장 한 줄이면 충분).

---

## 검수: 갈등축 가독성 (패스 / 페일)

**패스**

- 캐릭터 `description`만으로 **갈등축(존재↔인식 등)**을 독자가 말로 표현할 수 있다.
- 스토리 페이지를 순서대로 읽으면 **논점이 진행**된다(같은 말의 반복만 아니다).
- 맵·몬스터·스킬 중 최소 하나가 그 캐릭터의 축과 **같은 장**에서 만난다.

**페일**

- 태그·축·대가 없이 “강하고 신비한 전사” 수준이다.
- 국가 이름을 **요소(fire/water/…)와 동일시**해 읽히게 썼다.
- `storyPages`가 **연표 나열**이나 **설정 사전**처럼만 읽힌다(장면·선택·결과 없음).
